# Estou Flow

Estou Flow est un calendrier menstruel en français. Il permet de noter les dates de début des règles, de consulter leur historique et de visualiser les prochaines dates estimées.

## Ouvrir l’application

Ouvrez [`index.html`](index.html) dans votre navigateur. Ce fichier regroupe le HTML, le CSS et le JavaScript. Aucune installation n’est nécessaire.

## Utilisation

1. Indiquez la date de début des dernières règles.
2. Renseignez la durée habituelle du cycle et des règles.
3. Ajoutez les nouvelles dates de début au fil des cycles pour tenir votre historique à jour.

Les informations sont conservées dans le stockage local du navigateur. Vous pouvez les effacer depuis l’application. Les dates à venir sont indicatives et ne doivent pas servir de méthode contraceptive.
