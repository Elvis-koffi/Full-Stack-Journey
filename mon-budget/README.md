# Mon Budget

Mon Budget est une application en français pour suivre ses revenus, ses dépenses et son épargne mois par mois.

## Ouvrir l’application

Ouvrez [`dist/index.html`](dist/index.html) dans votre navigateur en gardant les autres fichiers du dossier `dist` à côté. Aucune installation n’est nécessaire.

## Fonctionnalités

- Suivre les dépenses réglées et prévues, avec un historique par mois.
- Planifier les opérations récurrentes et retrouver les échéances dans le calendrier.
- Visualiser les dépenses par catégorie et comparer les mois à l’aide de graphiques.
- Explorer les simulations et essayer l’application avec des données fictives.

Les données sont conservées dans le navigateur. Exportez une sauvegarde JSON pour pouvoir les restaurer après un changement de navigateur ou un effacement des données locales.

Pour le détail des calculs, des simulations et des sauvegardes, consultez le [mode d’emploi](Mode%20d%E2%80%99emploi.md).
